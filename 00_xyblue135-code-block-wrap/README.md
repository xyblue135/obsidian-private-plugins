# xyblue135 · 代码块增强

> **开源插件**：xyblue135 维护的开放源代码插件，仓库公开、可自由查看与复用。
> **兼容原则**：插件 ID 保持 `00_xyblue135-code-block-wrap`，升级包不携带 `data.json`，覆盖安装时保留用户本地配置与历史状态。

维护者：**xyblue135**
版本：**1.2.1**

---

这是一个极简 Obsidian 代码块插件，只处理围栏代码块的显示和换行，不影响普通正文，也不影响行内代码。

## 功能

- 默认关闭代码块自动换行。
- 长代码保持真实单行，不会被视觉折成多行。
- 超长代码不会把代码块撑出笔记宽度。
- 阅读模式 / 已渲染 Live Preview 中，长代码只在代码区域内部横向滚动。
- 重新整理代码块顶部布局：
  - 顶部增加独立工具栏。
  - Obsidian 原生复制按钮移动到工具栏右上角。
  - 复制按钮不再挡住第一行代码。
  - 复制按钮统一显示为小型“重叠方框”图标。
- Live Preview / Source Mode 编辑代码时，同样给顶部复制控件预留独立区域。
- 左侧 Ribbon 可以切换自动换行。
- 命令面板提供“切换代码块自动换行”。
- 每次 Obsidian / 插件重新加载后，自动恢复为“不换行”。
- 不修改 Markdown 文件本身。

## 安装

把整个文件夹复制到：

```text
<你的仓库>/.obsidian/plugins/00_xyblue135-code-block-wrap/
```

Obsidian 实际运行至少需要：

```text
manifest.json
main.js
styles.css
```

然后：

1. 重启 Obsidian，或者重新加载应用。
2. 打开“设置 → 第三方插件”。
3. 开启 **xyblue135 · 代码块增强**。

## 从 v1.0.0 更新

建议覆盖后执行一次：

```text

```

或者直接重启 Obsidian。

## 编辑模式的说明

Obsidian 的 Live Preview / Source Mode 在“正在编辑围栏代码块”时，CodeMirror 会把代码块拆成多行 `.HyperMD-codeblock`，并没有像阅读模式那样提供一个统一的 `<pre>` 父容器。

因此 v1.1.4 的处理方式是：

- 阅读模式 / 已渲染代码块：整个代码区统一横向滚动。
- 正在编辑的代码块：每一行保留内部滚动能力，但隐藏自己的滚动条；插件在整个代码块最底部创建唯一一个总横向滚动条。
- 总滚动条宽度按该代码块的最长一行计算；拖动它时，块内所有代码行统一横向移动。
- 开启自动换行后，总滚动条自动隐藏。

这样一个代码块无论有多少条超长文本，都只会出现一个底部横向滚动条。

## v1.1.1 修复

- 修复 Properties / YAML frontmatter 元数据可能被重复显示的问题。
- 阅读模式和 Live Preview 的已渲染代码块现在只接管带 Obsidian 原生 `copy-code-button` 的真正围栏代码块。
- 保留原有代码块顶部工具栏、复制按钮、横向滚动与自动换行开关。

## v1.1.2

- 修复阅读模式下 YAML/frontmatter 元数据被作为代码块重复显示。
- 阅读模式仅接管 `.el-pre` 中的真实围栏代码块，并显式排除 `pre.frontmatter`。

## v1.1.3

- 修复 Live Preview / Source Mode 下“每一条超长代码行都出现一个横向滚动条”的显示问题。
- 一个 fenced code block 现在只在最底部显示一个横向滚动条。
- 总滚动范围由代码块中最长的一行决定。
- 触控板或 Shift+滚轮直接滚动某一行时，也会同步整个代码块。

## v1.1.4

- 修复 v1.1.3 切换编辑视图后可能自动增加空行的严重问题。
- 根因：v1.1.3 把自定义滚动条节点插入了 CodeMirror 的 `HyperMD-codeblock-end` 编辑行。
- 新版不再向 `.cm-content` / `.cm-line` 插入任何插件 DOM。
- 编辑模式唯一滚动条改为挂载到 `document.body` 的 fixed 浮层，仅进行视觉定位与 `scrollLeft` 同步。
- 仍保持“一个代码块只有最底部一个横向滚动条，范围由最长一行决定”。

## v1.2.0：紧凑深色 + 设置界面

本版本在 v1.1.4 的安全滚动条方案上新增了完整设置页：

- 默认启用“紧凑深色”代码块外观。
- 顶部工具栏默认从 32 px 缩小到 20 px。
- 复制按钮默认缩小到 16 × 16 px，图标默认 6 px。
- 设置 → xyblue135 · 代码块增强 中可实时调整：
  - 自动换行开关。
  - 紧凑深色 / 跟随 Obsidian 主题。
  - 是否显示左侧 `>_` 标记。
  - 工具栏高度。
  - 复制按钮与图标大小。
  - 代码区上下/左右内边距。
  - 圆角。
  - 横向滚动条高度。
  - 代码区、工具栏、边框、文字、弱化文字、悬停背景、强调色。
- 所有设置自动保存并实时生效。
- 提供“一键恢复推荐默认值”。
- 自动换行状态现在也会保存，不再因为重载插件而丢失。
