# Mirror Attachments 更新日志

## 1.6.6

- 命名策略升级为“智能命名”：图片与 PDF 等嵌入式资源继续使用毫秒级时间戳；ZIP、RAR、7Z、Office 及其他非嵌入式附件保留原文件名。
- 普通附件重名时自动追加 `(1)`、`(2)`……，不覆盖旧文件，也不再要求手工处理重名。
- 普通附件增加文件名安全清理：替换 Windows 非法字符、ASCII 控制字符，处理末尾句点/空格与 Windows 保留设备名，同时尽量保留中文、空格、括号等可读信息。
- 普通附件 Markdown 显示完整文件名与扩展名，例如 `[项目源码.zip](...)`。
- 一次粘贴多个附件时，Markdown 链接之间自动加入一个空行。
- 单个附件导入失败不再中断整批任务；新增目标目录失败、单文件失败、重名自动改名和批量成功提示。
- 设置页版本信息、规则卡片和说明同步更新为“时间戳嵌入资源 / 原名普通附件”的双策略。

## 1.6.5

- 明确 Markdown 插入规则：图片与 PDF 使用 `![]()` 直接嵌入；ZIP、RAR、7Z、DOCX、XLSX、PPTX 等普通附件使用 `[]()`。
- 设置页重新分为：存储结构、导入行为、Markdown 插入规则、目录一致性、快捷操作。
- 设置页新增规则卡片、版本徽标和说明提示，减少链接格式理解成本。
- 延续 v1.6.4 的 Windows 文件粘贴兼容修复：同时读取 `DataTransfer.files` 与 `DataTransfer.items` 并去重。

## 1.6.4

- 修复 Windows 文件资源管理器复制 ZIP / Office / PDF 等普通文件后，部分 Electron 环境粘贴无法生成链接的问题。
- 粘贴和拖入统一从 `files + items` 收集系统文件，并自动去重。

## 1.6.2

- 文件树右键 Markdown 可直接打开对应附件目录。

## 1.6.1

- Markdown 链接改为 Vault 根目录绝对路径。
- 图片 alt 固定为空。

## 1.6.0

- 附件统一改为毫秒级纯时间戳命名。该策略在 v1.6.6 起仅保留给图片与 PDF 等嵌入式资源。
