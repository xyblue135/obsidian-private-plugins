xyblue135-AI-Metadata v0.5.6 安装说明

推荐升级方式（保留原数据库）：
1. 先关闭 Obsidian，或禁用旧版插件。
2. 备份原目录：<Vault>/.obsidian/plugins/xyblue135-ai-metadata-demo/
3. 将压缩包中的 xyblue135-ai-metadata-demo 文件夹覆盖到原目录。
4. 本版本已经携带你原上传插件中的 data.json；不要另外删除或清空它。
5. 重新打开 Obsidian并启用“xyblue135-AI-Metadata”。

兼容说明：
- manifest 的插件 ID 仍是 xyblue135-ai-metadata-demo，因此 Obsidian 会把它视为原插件的升级版本。
- 只修改显示名称为 xyblue135-AI-Metadata。
- data.json 中原有 Tag 目录、更新日志、标签评分、错误记录等信息会继续保留；旧的 lastSeenSourceHash / lastSummaryHash / lastTagsHash 指纹字段会删除。
- v0.5.4 新增的“Summary 输入 Markdown 清理”仍为可选开关，旧 data.json 没有该字段时会自动采用默认值 false。


v0.5.6 识别规则：
- 默认：summary 有内容 = Summary 已完成；tags 有内容 = Tags 已完成。
- 如果只缺一个字段，批量/自动更新只生成缺失字段，不覆盖已经有内容的字段。
- “内容指纹 fingerprint 识别”默认关闭；开启后才会持久化 hash 并按正文变化重新判断。
- 关闭 fingerprint 时，数据库中的持久化指纹字段会自动清理。
